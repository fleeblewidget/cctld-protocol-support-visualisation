# cctld protocol support visualisation

Visualisation tooling for interpreting ccTLD technical profile data provided via https://github.com/fleeblewidget/cctld-maturity.

## Running via Docker

The easiest way to manage Python environment is often via Docker. A Dockerfile is provided:

### Prereqs

Build the image with `docker build -t cctld-maps .`

### usage

`CSV="<results.csv>" && docker run --rm -v "$PWD/output:/app/output" -v "$(realpath "$CSV"):/data/results.csv:ro" cctld-maps`

Substituting your own CSV file path in place of `<results.csv>` (e.g. you could use `sample/sample_cctld_dataset.20260721.csv`)

## Running on bare metal

### Prereqs

* Install python and pip
* `pip install -r requirements.txt`
* Obtain data from somewhere (sample provided in `/sample`)

### Usage

`python maps.py <results.csv>`

results.csv - Path to the ccTLD protocol CSV generated by the data gathering scripts
