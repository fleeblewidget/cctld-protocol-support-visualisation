# cctld-maturity-visualisation

Visualisation tooling for interpreting ccTLD maturity data provided via https://github.com/fleeblewidget/cctld-maturity.

# Prereqs

* Install python and pip
* `pip install -r requirements.txt`
* Obtain data from somewhere (sample provided in `/sample`)

# Usage

`python visualise.py <results.csv>`
  results.csv - Path to the ccTLD maturity CSV generated by the data gathering scripts
